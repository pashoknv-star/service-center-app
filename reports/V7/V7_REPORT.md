# V7 — вложения файлов в задачах: отчёт

Дата: 2026-11-16. Ветка `v7/attachments` (worktree `/home/hermes/wt/v7-att`). Исполнитель: Hermes (default).
Решения владельца (2026-11-16): выбор файлов — обычный системный диалог; права — admin и supervisor, viewer смотрит и скачивает;
supervisor прикрепляет только к задаче, которую создал сам, удаляет только свои файлы; при архивации вложения удаляются с сервера;
белый список форматов; до 10 файлов по 5 МБ; если лимит PHP меньше 6 МБ — берётся минимальный, без экспериментов;
в карточке — только значок, по клику модальное окно с выбором, перетаскиванием и полосой загрузки.

## Ш0. Лимиты прода

Временный файл-зонд со случайным именем в корне сайта, запрос с самого сервера (внешний IP VPS закрыт IP-фильтром Hostland), файл удалён (повторный запрос → 404):
`upload_max_filesize=256M`, `post_max_size=256M`, `max_file_uploads=20`, `memory_limit=512M`, `max_execution_time=600`, `file_uploads=1`, PHP 8.1.34, `finfo` есть.
Лимит ≥ 6 МБ → действует 5 МБ. Правило «минимум» заложено в код: `tf_max_file_bytes()` = min(5 МБ, `upload_max_filesize`, `post_max_size` − 64 КБ) (`api/task_files_lib.php:91`);
клиент берёт лимит с сервера (`GET api/task_files.php?limits=1`). Лимит nginx на тело запроса не проверялся (эксперименты запрещены); ответ 413 без JSON клиент показывает как «Файл больше N МБ».

## Ш1. Сервер

- Схема v13: таблица `task_attachments` (только добавление, `IF NOT EXISTS`, FK на `tasks` с CASCADE) — `api/db.php:359`, `api/schema.sql` (конец файла).
- Файлы: `<каталог БД>/task_files/<32 hex>` без расширения; на проде — `data/task_files/` (каталог закрыт `data/.htaccess` и своим `.htaccess` «Require all denied», создаётся самим PHP при первой загрузке — права веб-пользователя) — `tf_dir()` `api/task_files_lib.php:111`.
- `api/task_files.php`: список, загрузка (по одному файлу на запрос), скачивание (`attachment`; `inline` только картинки и PDF; `nosniff`; для картинок CSP `sandbox`), удаление; аудит `task.attach` / `task.detach`; версия задачи не меняется.
- Белый список (23 расширения): PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX, ODT/ODS/ODP, TXT, CSV, RTF, JPG/JPEG, PNG, WEBP, GIF, HEIC/HEIF, ZIP, 7Z, RAR — и по расширению, и по содержимому (`finfo`; ZIP-контейнеры — сигнатура PK; HEIC — бокс `ftyp`; очень короткий TXT/CSV без NUL-байтов) — `tf_types()` `:36`, `tf_check_type()` `:168`. SVG/HTML/исполняемые не принимаются.
- Права — `tf_can_upload()` `:251`, `tf_can_delete()` `:265`: admin — любая неархивная задача; supervisor — только `tasks.created_by` = его логин, удаляет только свои файлы; viewer — 403; аноним — 401; архивная — 409.
- Квоты: ≤ 10 файлов и ≤ 50 МБ на задачу; окончательная проверка после вставки в транзакции (параллельные загрузки).
- Архивация (`DELETE api/tasks.php`) удаляет записи вложений в той же транзакции, файлы — после commit; имена — в `audit_log` `task.archive.details.attachments_deleted` (`api/tasks.php:1317`).
- `attachments` (метаданные) в ответе задачи и списка — `api/tasks.php:335`.

## Ш2–Ш4. Интерфейс (`js/tasks.js`)

- Карточка: в шапке значок-скрепка со счётчиком (`attBtnHtml` `:1479`); нет файлов и прикреплять нельзя — значка нет.
- Окно (`attRender` `:1587`, стиль общего `.tk-modal`): список файлов (тип PDF/DOC/XLS/PPT/IMG/ZIP/TXT, имя, размер, кто и когда), картинки и PDF открываются в новой вкладке + значок «скачать», остальное скачивается по имени; × — удалить (с подтверждением); зона «Перетащите файлы сюда или Выбрать файлы»; очередь с полосой загрузки у каждого файла (XHR `upload.onprogress`, `attSend` `:1712`); ошибки — у своего файла; окно можно закрыть во время загрузки — загрузка продолжится, итог тостом.
- Проверка до отправки: формат, пустой файл, размер, 10 файлов (`attPrecheck` `:1510`).
- Список и Доска: бейдж «скрепка N» (`:421`); Календарь: скрепка на плитке (`:798`), повторы показывают вложения основной задачи.

- «В архив»: подтверждение предупреждает «Вложения (N файлов) будут удалены с сервера без возможности восстановления» (`:2417`).

- Найдено и исправлено в ходе приёмки: окно живёт в `body`, и клик внутри него index.html считал «кликом вне панели» — панель «Задачи» закрывалась под окном. Клик в окне больше не всплывает до `document` (`onAttClick` `:1786`), тесты V7-14a и A3b.

## Не проверено

- Лимит nginx Hostland на тело запроса (эксперимент запрещён); при 413 без JSON клиент пишет «Файл больше 5 МБ».
- Загрузка на проде под реальным логином (паролей у меня нет): проверяется запись веб-пользователем в `data/task_files` зондом и запрет прямого доступа (раздел «Выкладка»).
- Вложения не попадают в автоматические бэкапы (этап E6 отложен); при выкладке `data/task_files` не трогается.
- Supervisor сейчас не может создавать задачи (запись задач — только admin, `api/tasks.php` `require_admin`), поэтому «своих» задач у него пока нет: право прикреплять у supervisor заработает, когда он сможет создавать задачи (или если `created_by` будет его логином).
