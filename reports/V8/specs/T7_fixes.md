## Объём

1. **P2-1 (T5 #1) — выбор дат 📅 при смене года.** `js/trips.js` ~`:3113`, `:3208–3209`: год фиксируется при входе в режим. Исправить так, чтобы выбранные даты всегда относились к году, показанному в Матрице в момент выбора, и подсветка строки сотрудника не пропадала после смены года (либо смена года в режиме выбора блокируется / отменяет режим — выбери вариант и обоснуй). Тест в `tripsform`: смена года в режиме выбора → даты нужного года.
2. **P2-2 (T5 #2) — смена статуса в обход `action=confirm`.** `api/trips.php` POST ~`:434–437`, PUT ~`:788–821`: сервер принимает `status` в теле. Сделать: POST — только `forecast` (`confirmed` → 400 `invalid_status`); PUT — `status`, отличающийся от текущего, → 400 `status_change_forbidden` (смена статуса только `PUT …&action=confirm`); `status`, равный текущему, допустим (совместимость). Обратного перехода `confirmed → forecast` нет. Тесты в `tripsstatus`: (а) admin POST confirmed → 400, (б) supervisor PUT status=confirmed → 400, статус и заявки не изменились, (в) admin PUT forecast на подтверждённой → 400. Проверь, что ни один штатный путь UI (форма, Матрица, черновик) не шлёт `status` иначе, чем forecast при создании.
3. **P3-6 (T5 #6)** — подтверждённая командировка не может остаться без места: PUT с пустым `location` для `confirmed` → 400 `location_required`; в форме — ошибка у поля.
4. **P3-3 (T5 #3)** — тесты `tripsform`/`tripsstatus` не должны краснеть с 2027-01-01: год и дни года вычислять от текущей даты (или явно выставлять год Матрицы перед сценарием). Проверь, подменив дату (например, через фиктивное `Date` в браузере или переменную окружения сьюта), что сьюты зелёные и для 2027 года.
5. **P3-4 (T5 #4)** — флак сценария supervisor 📅 в `tripsform`: перед протяжкой ждать панель выбора и видимость ячейки (`scrollIntoView`), без голых `sleep`. Прогнать сьют 5 раз подряд — 5/5 зелёных, вывод в отчёт.

6. **P1-1 (T6 §4) — телефон при наборе с клавиатуры.** Набор цифра за цифрой `89991234567`, `79991234567`, `+79991234567` даёт «+7 (899) 912-34-56» и сохраняет неверный номер (`js/trips.js` `phoneNationalDigits`/`maskPhoneField`: префикс 7/8 отбрасывается только при 11 цифрах сразу). Нужно: первая «8» или «7», набранная сразу после «+7 » в пустом поле, — код страны, а не цифра номера; результат для всех трёх способов набора и для вставки — «+7 (999) 123-45-67», на сервер уходит полный номер `+7` + 10 цифр. Набор `9991234567` работает как сейчас. Тест в `tripsform`: **посимвольный** набор (по одному символу через CDP) всех четырёх форм.
7. **P3-5 (T5 #5) — решение владельца 2026-11-18: телефон обязателен только для «Подтвердить».** «На подтверждение» (прогноз) и «Сохранить» прогноза — без телефона; пустой телефон допустим, неполный/некорректный номер — по-прежнему ошибка у поля. «Подтвердить» без телефона — ошибка у поля, без запросов на сервер; на сервере `PUT …&action=confirm` для командировки без телефона → 400 `phone_required` (аналогично `location_required`), PUT подтверждённой с пустым телефоном → 400 `phone_required`.
