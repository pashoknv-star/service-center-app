## Дополнительный объём (п.7)

7. **Поле «Место назначения» в форме командировки.** Находка T1: в форме панели нет полей `location` и `comment`, поэтому командировка из формы всегда сохраняется с пустым `location`, а он уходит роботу как `trip.destination` (`api/trips.php` ~`:335`, payload). По документации карточка содержит destination (`reports/ARCHITECTURE_TRIPS.md:90`). Сделать:
   - поле «Место назначения» (`location`) — **обязательно для «Подтвердить»** (без него подтверждение не отправляется, видимая ошибка у поля); для «На подтверждение» — необязательно;
   - поле «Комментарий» (`comment`) — необязательно;
   - при правке существующей командировки поля заполнены сохранёнными значениями; поле статуса не добавлять (статус меняется только кнопками, п.5 основной спеки).
   - Серверная проверка: `PUT …&action=confirm` для командировки с пустым `location` → 400 `location_required` (понятный текст в `tripErrorMessage`). Создание прогноза без `location` по-прежнему разрешено.
