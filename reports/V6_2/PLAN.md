## Технические решения (выбраны координатором)
- **Метки без новой таблицы и миграции.** Поле `tasks.label` остаётся; теги хранятся через запятую, сервер нормализует (обрезка, без дублей, без пустых), лимит 50 → 200 символов, тег ≤ 30. API отдаёт дополнительно `labels: []`; строковое `label` сохраняется — интеграция n8n не ломается. Причина: меньше всего риска, нет шага с данными на проде.
  - На проде 11 из 12 задач с меткой, **у 2 метка уже содержит запятую** — после выкладки они покажутся как 2+ тега. Похоже, это и было намерение; если нет — скажите, сделаю иначе.
- **Перетаскивание и копирование — только мышь (ПК).** На телефоне (375 px) нет правой кнопки, а перетаскивание конфликтует с прокруткой; там остаётся «Править» в карточке. Расширение на касания — отдельно, если понадобится.
- Права: перетаскивание, копирование/вставка, «Править» — только администратор, как и вся правка задач.
