# E10 Err4 — пик-флоу «Добавить участника» + «Отмена» (фикс координатора)

Дата: 2026-09-02
Статус: исправлено, проверено реальными кликами мыши (CDP harness), деплой на прод.

## Жалоба (владелец)

1. Панель закрывается при удалении участника.
2. «+Добавить участника» → панель не уезжает влево → клик по карточке сотрудника — ничего.
3. «Новая командировка» → «Отмена» → панель полностью уезжает.

Ожидание (ТЗ): панель смещается влево до видимой кромки с кнопкой [Добавить
сотрудников]; матрица доступна; Ctrl+клик по карточкам; карточка-панель НЕ
выезжает; повторное нажатие edge-кнопки возвращает панель; участники с пустыми
датами. «Отмена» — возврат в меню панели.

## Корни (4 дефекта)

1. **Outside-click закрывал панель** — inline `onclick` (× участника,
   «Отмена») перерисовывает DOM во время всплытия клика; `event.target`
   отсоединён, `vacationPanel.contains()` → false → панель закрылась.
   Фикс: guard `event.target.isConnected === false → return` (index.html
   outside-click handler) + `.trip-btn`/`.trip-pick-edge` в `inBtn`-исключения.
2. **CSS-специфичность слайда** — `.trip-panel-slided` (0,1,0) проигрывал
   `.vacation-panel.open` (0,2,0) → `translateX(0)` побеждал, панель не уезжала.
   Фикс: `aside.vacation-panel.trip-panel-slided { … !important; }`.
3. **Edge-кнопка не возвращала панель** — после подтверждения пик
   оставался активным (кнопка менялась на «← Вернуть»), панель оставалась
   уехавшей. Фикс: `confirmEmployeePick` зовёт `endEmployeePick()` — один
   клик добавляет участников и возвращает панель.
4. **«Отмена» звала несуществующую модалку** — `closeTripModal()` в шаблонах
   showTripModal (легаси) вместо `closeTripForm()`. Фикс: замена вызовов.

## Верификация (CDP: real mouse clicks, elementFromPoint-проверка попадания)

| Шаг | Результат |

| S1 «+ Добавить сотрудника» | slided=true, pickActive=true, closes=0 |
| S2 Ctrl+click карточка | selected=1, picked=["1"], карточка-панель НЕ открыта, closes=0 |
| S3 edge «✓ Добавить сотрудников» | slided=false (панель вернулась), rows=1, name «E9 Test Employee», dates ["",""] (пустые), edge удалён |

«closes» — счётчик-ловушка на `vacationPanel.classList.remove('open')`: 0 на
всех шагах (раньше именно он закрывал панель).
