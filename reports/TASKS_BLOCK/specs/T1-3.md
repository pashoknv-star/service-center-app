# T1-3 Иконка (вариант B) и рамка срока в матрице (frontend)
Прочитать `00_COMMON.md`, TZ §4, `mockups.html` (раздел 1). Зависит: T1-2 принят (панель и `openTasksPanel`).

Objective: отображение задач в общем календаре (матрице отпусков).

Scope: новый модуль `js/tasks_matrix.js` (оверлей по образцу trips-overlay, см. `js/trips.js`, `js/test_trips_overlay.js`) + точечные anchor-вставки в `index.html`. Out of scope: логика задач/API, n8n.

Требования:
1. В ячейке дня сотрудника — круг `#0088CC` со счётчиком открытых задач, СТАРТУЮЩИХ в этот день (вариант B из макета); красный круг, если у любой из них `conflict`. Только открытые задачи. Закрытая/архивная — без иконки. Иконка только на первом дне срока.
2. Весь срок (все ячейки периода, включая выходные/отпуск) — тонкая рамка `1.5px solid var(--rt-blue)`, radius 8, лёгкое свечение, как у `.photo` (index.html ~304–315); без заливки; не перекрывает цвета статусов матрицы и не мешает кликам/выбору ячеек/Ctrl-мультивыбору/пик-режиму командировок.
3. Клик по иконке → `openTasksPanel({employeeId, date, view:'calendar'})`. Доступно всем ролям (supervisor/viewer — чтение).
4. Данные: один запрос `GET api/tasks.php?from&to` на видимый диапазон/год, кеш; обновление после мутаций в панели. Без влияния на автосохранение/guard-логику save.php.
5. Несколько исполнителей — иконка и рамка в строке каждого. Производительность: до ~50 сотрудников × год без заметной просадки (замерить, привести цифры).
6. Mobile compact (P13): не ломать скролл.

Acceptance: AC-2, AC-1(иконки для supervisor/viewer); тесты геометрии/семантики (по образцу e51/e52) на: иконка только на первом дне, рамка по всему сроку, закрытая задача без иконки, клик открывает панель; существующие e51/e52/hygiene/trips сьюты зелёные; `node --check` inline-скриптов; `verify_all.sh` → GATE: PASS.
Artifacts: код, тесты, `T1-3_REPORT.md` с номерами строк вставок, скриншоты/DOM-проба, коммит.
