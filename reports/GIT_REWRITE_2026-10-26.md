## Последствия и что ещё нужно знать

1. **Все старые клоны устарели.** Любой клон или worktree, сделанный до 2026-10-26, нельзя пушить: он вернёт ПДн. Нужен свежий `git clone` или `git fetch && git reset --hard origin/main`. На хосте других клонов нет (проверено).
2. **GitHub-кэш:** старые коммиты ещё какое-то время доступны по прямому SHA (например, `/commit/101c846…`) до сборки мусора на стороне GitHub. Репозиторий приватный, так что риск низкий. Для гарантированного удаления владелец может написать в GitHub Support «remove cached views / unreachable objects» и указать репозиторий.
3. **Прод не затронут.** На проде до сих пор старый `index.html` с реальными ФИО. Устраняется хотфиксом HF-1 и выкладкой по «Деплой».
4. В рабочем `index.html` сейчас стоят плейсхолдеры `Сотрудник NN`. HF-1 удаляет эти блоки полностью, а `scripts/check_no_pii.sh` не даст закоммитить ФИО или плейсхолдеры снова.
5. Правило на будущее (внесено в AGENTS.md): в репозиторий не коммитятся реальные ПДн; dev-данные только синтетические.

Скрипт перезаписи (`scrub.py`, git-filter-repo 2.47 через Python API) и карта фамилий хранились в scratch координатора. Карта с реальными фамилиями удалена после перезаписи.
