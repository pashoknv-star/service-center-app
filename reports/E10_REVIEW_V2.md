# Ревью v2-замечаний (E10) — корневые причины и план

**Дата:** 2026-09-01. **Вход:** Замечания_по_релизу_Механика_командировок_v2.md (11 закрыто ✅, 7 открыто). **Дерево:** `6bdf112`.

## Корневые причины (по коду)

### П4 — Ctrl-выбор в матрице (самый большой)
1. **Затемнение:** `.trip-row-dimmed { opacity: 0.4 }` — тёмное затемнение всех невыбранных строк ЦЕЛИКОМ (вкл. ФИО). Нужно: бледно-серый фон-подложка (light-gray wash), текст ФИО читаемый; выбранные — default.
2. **Карточка не закрывается:** ctrl+click по строке ФИО не закрывает «Карточку сотрудника» и не возвращает матрицу в полноразмерный формат (нет такой логики в обработчике index.html ~3646).
3. **Popup не фильтруется:** popup ячейки одинаков для всех. Нужно: невыбранные — popup полностью отключён; выбранные — только «Командировка» и «Отгул» (скрыть work/vacation/sick, образец: role-supervisor CSS-фильтр index.html:1548-1550).
4. **Нет автот水forms:** выбор состояния «Командировка» на диапазоне ячеек должен автоматически открыть форму «Новая командировка» со ВСЕМИ выбранными сотрудниками и этим диапазоном дат (одинаковым для всех). Сейчас renderTripFormInPanel зовётся только из popup-пути с одним сотрудником (index.html:5092).

### П7+П8 — форма обрезана снизу
5. Блок `.vacation-legend` («Обозначения:») рендерится над `#tripsListView` на вкладке «Командировки» (index.html ~1979-1990), съедает высоту → блок кнопок «Отмена/Сохранить» уходит за нижнюю границу панели. Легенда нужна только на вкладке матрицы. Фикс: скрывать при `tab=trips` (класс на панель в switchTab + CSS).

### П12 — пустой блок «Участники»
6. В renderTripFormInPanel лейбл «Участники» + пустой контейнер всегда рендерятся. Скрывать, пока 0 участников (остаётся только «+ Добавить сотрудника»).

### П13 — pick-флоу сломан целиком
7. Панель НЕ уезжает (геометрия slide не применяется к текущему состоянию панели), появляется отдельная кнопка-док за панелью; основное поле уезжает вниз; клики по карточкам ничего не выбирают; кнопки закрытия формы не работают. Требуется переделка: клик «+ Добавить сотрудника» → панель командировки уезжает влево за экран, на правом краю панели остаётся мини-кнопка-«язычок» (в 5 раз короче), видимая у левой границы экрана → основное поле доступно → ctrl+клик по карточкам (стандартная подсветка .selected, карточка-панель НЕ открывается) → повторный клик по язычку → панель возвращается в полноразмерный формат, выбранные добавлены участниками с ПУСТЫМИ датами (даты заполняет пользователь).

### П14 — вход из карточки сотрудника
8. Наследует П7 (обрезанная форма) и П15 (selection-модалка за панелью). Закрывается фиксами П7/8/15.

### П15 — окна за панелью
9. `.vacation-panel { z-index: 2100 }` (index.html) ВЫШЕ портала `#tripModalRoot { z-index: 1500 }` → selection-модалка и др. всегда за панелью. Фикс: поднять портал выше 2100 (например 2500).

### П17 — «Удалить» мертва
10. **Найден точный баг:** в renderTripFormInPanel инлайн-onclick рендерится как `handleDeleteTripClick(${trip.id})` → `handleDeleteTripClick(trip_6a95...)` — строка без кавычек → ReferenceError при клике. Та же болезнь у «Подтвердить» и «Сохранить» (`saveTrip(${trip ? trip.id : 'null'})`). Фикс: экранировать `('${trip.id}')`.
