## Объём

**A. Название зоны.** «В2С» → «Директор СЦ» во всём видимом: `ZONES` в `index.html` (~2180) и `js/storage.js` (~34), `<select id="editDept">` (~2130), группировка матрицы (~2899), экспорт/импорт и всё, что найдёт `grep -rn "В2С"` (кроме отчётов). Таблица `groups`: `g3.name` → «Директор СЦ» идемпотентной миграцией в `api/db.php` `migrate()` (v10 → v11; только `WHERE id='g3' AND name='В2С'`; повтор — no-op). Проверить, что ничто не сопоставляет зону по имени «В2С» (импорт xlsx/csv, `api/*.php`, `scripts/*`); если сопоставляет — принимать оба имени.

**B. Золотая плитка.** Зона 3 (`.zone[data-zone="3"]`): благородный золотистый (мягкий градиент старого золота, золотая рамка, без кислотного жёлтого). Боковая плашка `.zt`: золото + скромная россыпь мелких бриллиантов (5–9 штук, CSS/inline SVG, без внешних файлов, без анимации или с едва заметным мерцанием ≤ 1 элемента). Название «ДИРЕКТОР СЦ» читаемо (контраст ≥ 4.5:1). Карточка сотрудника в зоне — тонкая золотая рамка у фото. Мобильные правила (~1660) — тоже. Остальные зоны не меняются.

**C. Матрица отпусков.** Сотрудники зоны 3 — самой верхней группой (над всеми остальными, независимо от порядка `ZONES`), строка с подписью группы «Директор СЦ». Подсветка органичная и неяркая: лёгкий золотой тон фона строки (≈6–10% непрозрачности) + тонкий золотой акцент слева у ФИО. Цвета отпусков, «сегодня», hover, выделение диапазона, иконки задач (`js/tasks_matrix.js`) и pick-панель (e51/e52) работают как раньше. Пустая зона 3 → группы нет. Если строки ищутся по индексу где-то ещё — перевести на атрибут сотрудника. Параллельная V6-1 добавляет `window.openMatrixAt` (ищет строку по id сотрудника) — не мешать: у строки должен остаться/появиться атрибут с id сотрудника.

**D. Фото.** Картинка «Дон Корлеоне». Источник: Wikimedia Commons, файл со свободной лицензией или Public Domain (например кадры трейлера «Крёстный отец» 1972 г., PD в США). В отчёт: URL файла, автор, лицензия. Квадрат, ≤ 300×300, JPEG ≤ 60 КБ → `reports/V6/assets/director_avatar.jpg`. Если свободного изображения нет — `kanban block` с найденными вариантами, НЕ брать с произвольных сайтов. Скачивание из интернета разрешено только для этого пункта.

**E. Данные на проде (подготовка, НЕ выполнять на проде).** Прод-CLI PHP 5.3 — PHP-скрипты там не запускаются; есть `sqlite3` 3.26. Подготовить:

Идемпотентно (повтор — 0 изменений), ровно 1 совпадение, иначе ничего не менять. История отпусков/командировок Костецкого НЕ трогается: это решит владелец на «Деплой», в DRY-RUN только счётчики.
