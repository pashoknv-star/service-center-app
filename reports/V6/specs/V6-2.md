# V6-2 — «Задачи»: Календарь по часам (как Outlook) и время с шагом 30 минут (R-3, R-6, R-9, R-10, R-11)

Исполнитель: sd_worker_04. Worktree: `/home/hermes/wt/v6-2`, ветка `v6/calendar`. Сначала прочитать `reports/V6/specs/00_COMMON.md`.

## Объём (слова владельца → что сделать)

| R | Владелец | Сделать |
|---|---|---|
| R-3 | «В карточке создания задачи, блок Срок, при выборе времени минутный блок сделать с интервалом в полчаса, а не одна минута» | Поля `startTime`/`endTime` формы: вместо `<input type=time>` — выпадающий список «—, 00:00, 00:30 … 23:30». Если у существующей задачи время не кратно 30 — оно показывается отдельным выбранным пунктом и сохраняется без изменений, пока его не сменят. Контракт API (`start_at`/`end_at`) не меняется |
| R-6 | «В Календаре в ячейке с задачей выделять только тему задачи, исполнителей убрать» | Плитка календаря: время + тема (`title`, жирно). ФИО и описание из плитки убрать; исполнители — в `title` (подсказке) и в карточке. Метки «конфликт», «не проверено», «без исполнителя» — компактно, как значки |
| R-9 | «Календарь (неделю и день) разлиновать по часам с 0 до 23:59, равномерно, равным отступом, карточка задачи помещается в эту ячейку по аналогии с Outlook» | Режимы «Неделя» и «День»: колонка часов 00…23 слева, 24 строки равной высоты (~40–48px), линии на каждом часу (полчаса — бледная линия). Плитка абсолютно позиционирована: top = начало, height = длительность (минимум 30 мин; задача только со временем начала = 1 ч). При открытии прокрутка к 08:00; при «Сегодня» в текущей неделе — линия «сейчас». Задачи без времени и многодневные — полоса «Весь день» над сеткой (как в Outlook); у многодневной со временем — в «Весь день» на всех днях |
| R-10 | «При нажатии на конкретную ячейку конкретного дня, конкретного часа должна выходить форма Новая задача» | Клик по пустому месту ячейки (день, час) → форма новой задачи: дата = день, начало = hh:00 (клик в нижней половине часа — hh:30), конец = +1 ч, вид «Период» в пределах дня (если «Срок (один день)» поддерживает только начало — выбрать наиболее естественное и описать в отчёте). Только admin; для supervisor/viewer клик ничего не делает. Клик по плитке — как сейчас (открывает карточку) |
| R-11 | «Задачи, которые пересекаются по времени в одном дне, должны стоять рядом друг с другом по аналогии с Outlook» | Раскладка дня: группы пересекающихся задач делят ширину колонки на N равных дорожек (классический алгоритм колонок Outlook/Google), непересекающиеся — во всю ширину |
