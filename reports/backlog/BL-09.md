# BL-09 — Матрица: выделение диапазона протяжкой не оставляет меню открытым (P2-1 из V8-T6)

**Решение владельца (2026-11-18):** отложить в бэклог. Не запускать без команды владельца.

## Симптом

admin → «Матрица отпусков» → зажать кнопку мыши на ячейке дня, протянуть по строке сотрудника на несколько дней, отпустить. Ячейки подсвечены (`range-selecting`), меню «Рабочий день / Отпуск / Больничный / Командировка / Отгул / Очистить» не появляется; следующий одиночный клик по дню «проглатывается» (`rangeActive`).

## Причина (по диагностике V8-T6, не перепроверено координатором)

`mouseup` на документе открывает меню, затем браузер отправляет `click` на общего предка (`TR.matrix-hover-row`, т. к. нажатие и отпускание — на разных ячейках), и обработчик «клик вне меню» (`index.html` ~`:3680`) закрывает меню.

## Контекст

- Не регрессия V8: воспроизводится идентично на `80577c5` (до V8), Chromium 145. На проде и в других браузерах не проверялось.
- Обходные пути работают: клик по одному дню → «Командировка»; Ctrl+клик по строкам → клик по дню.
- Источник: `reports/V8/T6_ACCEPTANCE.md` §4 «P2-1», скриншот `reports/V8/screens/T6_*matrix_range_drag*.png`.

## Критерии приёмки (при запуске)

Протяжка по нескольким дням → меню открыто → «Командировка» → форма с этим диапазоном. Одиночный клик, Ctrl+клик, режимы выбора 📅 и «+ Добавить сотрудника» не сломаны; сьюты `e51`/`e52`/`hygiene`/`tasksmx`/`tripsform` зелёные.
