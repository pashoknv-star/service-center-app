## Объём (слова владельца — в 00_COMMON, пп. 4–6)

1. **Форма задачи** (`js/tasks.js`, после строки «Вложения», `fieldRow('Вложения', …)` ~2050): строка «Связанные задачи» — `textarea` (`data-tk-field="linksText"`), только для admin (у остальных формы записи нет). Подсказка под полем: «Введите (()) и поставьте курсор между скобками — откроется список задач». Состояние поля входит в `S.form`/сохранение/«грязную» форму как остальные поля; отправляется как `links_text`; ошибки сервера (`link_self`, `link_unknown`, `link_target_archived`, `links_too_many`) — понятные тексты рядом с полем.
2. **Ключ `(())`:** когда у `textarea` курсор оказывается между `((` и `))` (проверка на `input`, `click`, `keyup`/`selectionchange`) — открывается модальное окно выбора (по образцу окон модуля, `S.att` как пример структуры окна; «по аналогии со списком исполнителей» — поиск без учёта регистра по названию). Данные — `GET api/tasks.php?pick=1` (кэш в `S`, сброс при sync/сохранении). Список: название, статус «Открыта/Закрыта», дата; сама редактируемая задача исключена; клавиатура (↑/↓/Enter/Esc), фокус возвращается в `textarea`. Выбор подставляет вместо `(())` токен `((ID|название))` (название очищено от `( ) |` и переводов строк, ≤80 симв.), курсор — после токена. Отмена оставляет `(())` как есть и повторно окно не открывает, пока курсор не покинет скобки и не вернётся.
3. **Карточка задачи** (панель деталей, `js/tasks.js` ~1842; «блок Доска»): под «Описанием» — блок «Связанные задачи»: текст `links_text` с токенами, заменёнными на активные ссылки-чипы (название — актуальное с сервера; остальной текст — как есть, через `esc()`, переводы строк сохранены), затем строка чипов «Также связана с:» для входящих связей, которых нет в собственном тексте. Блок не показывается, если связей и текста нет. Перечёркнутая ссылка (`archived`) — `<s>`/класс, подсказка «Задача удалена», клик ничего не делает. Видно всем ролям.
4. **Клик по ссылке → «Список»:** `S.filters.rel = <id задачи, из чьей карточки кликнули>`, вид переключается на «Список», данные — `GET api/tasks.php?related=<id>`; первая строка — исходная задача **без выделения**, затем остальные связанные; открытые и закрытые вместе; другие фильтры при `rel` не применяются. В панели фильтров плашка «Связанные задачи: <название>» и «×» (сбрасывает `rel`, возвращает обычный Список). Работает под admin/supervisor/viewer. Ссылка внутри Доски/Календаря открывает карточку и т.д. как сейчас — менять только описанное.
5. **Sync/перерисовка:** `render()` не должен сбрасывать курсор и текст в `textarea`, пока оно в фокусе и форма открыта (проверь существующую защиту `dirty`, T1-11, и не ломай её); при sync в открытой карточке связи обновляются.
6. **CSS** — в существующих файлах (`css/*`); чипы читаемы при 1280 и 375, длинные названия переносятся/обрезаются многоточием с `title`.
