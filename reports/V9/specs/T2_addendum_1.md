# V9-T2 — addendum 1 (контракт T1 принят координатором)

Старт T2 от коммита `main` = см. комментарий `START:` на карточке. Контракт API — `reports/V9/T1_REPORT.md` §2 (истина). Дополнительно, из приёмки T1:

1. **Tasks не синхронизируются между клиентами** (`api/sync.php` задач не содержит; `dirty` относится к матрице). Чтобы связь появилась в карточках обеих задач без перезагрузки страницы — после успешного POST/PUT формы вызвать `load(true)` (перечитать список). Другие окна обновятся при их обычном обновлении списка — это не дефект T2.
2. `links[]` приходит и в строках списка, и в `?related`, и в карточке: `{id,title,status,archived(0|1),direction:'out'|'in'}`. Источник чипов в карточке — `links[]` (актуальные названия), а не токены текста; токен без записи в `links[]` (например, ID удалённой связи) рисовать как неактивный текст «задача не найдена», не как ссылку и не `undefined`.
3. `?related=<id>`: ответ `{ids, tasks[], truncated?}`; `truncated:true` → в плашке фильтра добавить «показаны первые 200». Ошибки: неизвестный id — 404 `not_found`, архивный — 409 `task_archived` (в UI — сообщение, фильтр не включать, Список остаётся прежним).
4. `?pick=1` отдаёт ≤2000 неархивных (`{id,title,status,start_at}`); `start_at` может быть датой без времени.
5. Связь живёт, пока токен остался хотя бы в ОДНОМ из двух текстов: если удалить токен у задачи 2, а у задачи 1 есть встречный токен на задачу 2 — связь остаётся (у задачи 2 она станет `direction:'in'`). Это ожидаемо; тест «убрал токен — связь пропала» делать на паре без встречного токена.
6. Допустимые символы ID — `[A-Za-z0-9_.-]{1,64}` (реальный id `task_<hex>.<цифры>` содержит точку): регулярку разбора в JS согласовать с серверной (`TASKS_LINKS_ID_RE`, `api/tasks_links.php`). Название в токене не должно содержать `))` и переводов строк (очищать на клиенте `( ) |`).
7. Ошибки записи для показа рядом с полем: 422 `link_self` / `link_unknown` / `links_too_many`, 409 `link_target_archived`, 400 `invalid_links_text`, 409 `VERSION_CONFLICT` — использовать `message` сервера.
8. В `tests`: сьют `tasklinks` (37) не трогать; BASELINE менять только добавлением своего `tasklinksui`.
