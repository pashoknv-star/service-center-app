Решения по ТЗ/контракту:
- **Источник чипов — `links[]`** (актуальное название, `archived`, `status`), а не снимок из токена. Токен без записи в `links[]` рисуется неактивным «задача не найдена» (addendum п. 2). Перечёркнутая (`archived=1`) — `<s class="tk-lk-gone" title="Задача удалена">`, не `<a>`, клик ничего не делает.
- **Регулярка токена** согласована с серверной: ID `[A-Za-z0-9_.-]{1,64}` (в т.ч. точка), название — без перевода строки до первых `))`. Название при вставке очищается от `( ) |` и переводов строк, ≤ 80 символов.
- **Сохранение:** `links_text` отправляется всегда (пустая строка = очистить связи этой задачи); после успеха `load(true)` (addendum п. 1) — связь видна в карточке второй стороны. Ошибки `link_self/link_unknown/link_target_archived/links_too_many/invalid_links_text` — рядом с полем, набранный текст и курсор сохраняются; `VERSION_CONFLICT` идёт прежним путём формы.
- **`?related`:** 404 `not_found` / 409 `task_archived` → сообщение, фильтр не включается (при клике) или снимается (при перечитывании открытого фильтра, затем обычный `load`); `truncated:true` → в плашке «· показаны первые 200».
- **Исходная задача в `rel`-Списке** — первой строкой без выделения (атрибут `data-tk-rel-src`, без CSS-класса выделения), остальные — по обычной сортировке Списка; другие фильтры при `rel` не применяются; открытые и закрытые вместе.
- **Окно выбора** не входит в `DOM.root` (подложка в `body`), поэтому обработчик «×/Отмена» — свой (`onLpClick`); в `ACTIONS` добавлен `lpClose` только ради сьюта `tasksui` (S1: каждая `data-tk-act` имеет обработчик).
- Данные окна — `GET ?pick=1`, кэш `S.pickCache`; сбрасывается при открытии формы, после сохранения и при `onRemoteChange`; редактируемая задача из списка исключена; поиск без учёта регистра; в окне ≤100 строк (остальное — «уточните поиск»).
- Правка `index.html` не потребовалась (экспортов `window.Tasks.*` из разметки новых нет).
