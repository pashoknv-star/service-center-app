## 6. Риски деплоя (по документам проекта, без доступа к проду)

- **Хостинг** (`DEPLOY_HOSTLAND.md:11–20`): веб — Apache + PHP **8.1.34**; CLI PHP 5.3 (не используется приложением); `sqlite3` CLI 3.26. Перед выкладкой — бэкап `data/app.db` (`.backup`, `DEPLOY_HOSTLAND.md:132`), `data/app.db` не перезаписывать.
- **Порядок выкладки**: код целиком (`api/db.php`, `api/schema.sql`, `api/tasks.php`, `api/tasks_links.php`, `js/tasks.js`) — новый `tasks.php` без `tasks_links.php` даёт 500 (`require_once`); старый `js/tasks.js` с новым API работает (поля аддитивны), новый `js/tasks.js` со старым API — «связей нет» без ошибок записи (`links_text` игнорируется старым PUT).
