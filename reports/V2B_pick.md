# V2-B: pick-флоу «Добавить сотрудника» (П13) + вход из карточки (П14)

**Задача:** t_e2be9846. **Исполнитель:** sd_worker_04 (реализация) + координатор (2 доверительных фикса). **Статус:** ✅

> Примечание координатора: воркер закрыл задачу без отчёта-артефакта; данный файл составлен координатором при приёмке на основе дифа. Два дефекта найдены приёмкой и исправлены координатором (тривиальные, 2 строки — прецедент R2-fix/E9).

## Реализовано (sd_worker_04)

1. **Слайд панели:** `startEmployeePick` добавляет `.trip-panel-slided` (translateX(-100% + 46px)) — панель уезжает влево, видна кромка 46px (js/trips.js ~2330).
2. **Язычок-кнопка:** `.trip-pick-edge` «✓ Добавить сотрудников» на видимой кромке уехавшей панели (js/trips.js 2337-2352, CSS 809-830). Первый клик = подтвердить выбор, повторный = возврат в режим формы (флаг `_employeePickConfirmMode`).
3. **Ctrl+клик по карточкам на странице:** capture-листенер на document перехватывает Ctrl+клик по `.employee` ДО хост-обработчика → стандартная подсветка `.employee.selected`, карточка-панель НЕ открывается (suppressInfoPanel).
4. **Возврат с пустыми датами:** `confirmEmployeePick` → `syncPickedEmployeesToForm` → участники в форме с `startDate: ''` (пользователь заполняет сам).
5. **П14:** вход из карточки сотрудника открывает ту же in-panel форму (selectTripForEmployee → openTripModal → renderTripFormInPanel); selection-модалка поверх панели (z-фикс V2-A).

## Фиксы координатора (приёмка)

1. **`closeTripForm` не была экспортирована** в `window.Trips` — «Отмена»/«×» (`window.Trips.closeTripForm()`) бросали ReferenceError → форму нельзя закрыть без F5 (симптом П13 «кнопки закрытия не работают»). Добавлен экспорт (js/trips.js ~1941).
2. **Mid-pick закрытие не возвращало панель:** closeTripForm не вызывал endEmployeePick — панель оставалась за экраном с мёртвым язычком. Добавлен вызов endEmployeePick при `_employeePickActive` (js/trips.js 1093-1097).
